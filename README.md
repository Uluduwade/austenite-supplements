# Austenite Supplements
npm install && npm run dev   (build: npm run build)
Edit contact details in src/config.js and products in src/data/products.js.
Add photos: put files in /public/images and set img: '/images/name.jpg' on a product.
On Vercel, visitors detected in Sri Lanka are shown LKR unless they have selected a currency manually; visitors elsewhere default to GBP.
